# decision-making-app

## Description
Cette application web permet de résoudre des problèmes de décision multicritères en utilisant la méthode 

## Utilisation 
1. Entrez vos critères et vos alternatives.
2. Remplissez la matrice de comparaison par paires.
3. Le système vérifie automatiquement la cohérence.
4. Si cohérent, l'application propose la meilleure alternative.
